# Developer Portfolio Website

## Project Overview

This is a modern and responsive Developer Portfolio Website built using HTML and CSS. The portfolio is designed to showcase personal information, technical skills, projects, education, and contact details in a clean and professional layout.

The website focuses on responsive web design, smooth navigation, and an attractive user interface to provide a great user experience across different devices.

---

## Project Objectives

- Build a professional developer portfolio.
- Showcase personal skills and projects.
- Practice responsive web design using HTML and CSS.
- Create a modern and user-friendly interface.
- Improve frontend development skills.

---

## Features

- Responsive Design
- Home Section
- About Section
- Skills Section
- Projects Section
- Contact Section
- Social Media Links
- Smooth Navigation
- Clean and Modern UI

---

## Technologies Used

- HTML5
- CSS3
