#  Brew Haven - Coffee Shop Website

## Project Overview

Brew Haven is a modern and responsive Coffee Shop Website developed using HTML and CSS. The website is designed to provide an engaging and visually appealing experience for coffee lovers. It showcases different coffee varieties, special offers, customer reviews, and essential business information through a clean and user-friendly interface.

The project focuses on responsive web design, attractive layouts, and smooth navigation to ensure a seamless browsing experience across desktops, tablets, and mobile devices.

---

## Project Objectives

- Build a responsive Coffee Shop website.
- Create a clean and modern user interface.
- Improve frontend development skills using HTML and CSS.
- Practice responsive layouts and page navigation.
- Deliver a user-friendly browsing experience.

---

## Features

- Responsive Design
- Sticky Navigation Bar
- Hero Section
- Popular Coffee Menu
- Special Offer Section
- Why Choose Us Section
- Customer Reviews
- About Us Page
- Contact Page
- Contact Form
