# TaskFlow - To-Do List Web Application

## Project Overview

TaskFlow is a responsive and interactive To-Do List web application developed using **HTML5**, **CSS3**, and **JavaScript**. It enables users to efficiently manage their daily tasks by adding, completing, and deleting tasks through a clean and user-friendly interface.

The project demonstrates JavaScript DOM manipulation, Local Storage implementation, input validation, and responsive web design while providing a modern and engaging user experience.

---

## Project Objectives

- Build an interactive To-Do List application.
- Practice JavaScript DOM manipulation.
- Implement Local Storage for persistent task management.
- Create a responsive and user-friendly interface.
- Enhance frontend development skills.

---

## Features

- ✅ Add New Tasks
- ✅ Delete Tasks
- ✅ Mark Tasks as Completed
- ✅ Task Counter
- ✅ Local Storage Support
- ✅ Enter Key Support
- ✅ Input Validation
- ✅ Responsive Design
- ✅ Modern Glassmorphism UI
