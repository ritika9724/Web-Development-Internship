# 📸 Responsive Photo Gallery

## Project Overview

Responsive Photo Gallery is a modern and responsive web application built using **HTML5** and **CSS3**. The project demonstrates the effective use of **CSS Flexbox** and **CSS Grid** to create a visually appealing and mobile-friendly gallery layout.

The website provides a clean user interface with a responsive navigation bar, hero section, image gallery, about section, contact form, and footer. It adapts seamlessly across desktop, tablet, and mobile devices.

---

## Project Objectives

- Build a responsive webpage using HTML and CSS.
- Implement CSS Flexbox for layout alignment.
- Use CSS Grid to organize gallery images.
- Create a modern and user-friendly interface.
- Practice responsive web design using media queries.
